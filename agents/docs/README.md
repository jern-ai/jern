# Iron.Agent.Docs

A documentation-only [iron](https://github.com/ademar/IronAgent) agent, and the
example of swapping the brain: the default loop with a tool surface narrowed in
~10 lines of source — reads, searches, and Markdown edits; no shell.

Run it with `iron run --agent agents/docs "task"`; test it with
`iron test agents/docs`.
