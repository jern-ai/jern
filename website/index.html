From repository to evidence

Four deliberate steps. No hosted runner required.

  1. 01

    Connect

    Select only the repositories Jern Cloud may inspect through the GitHub App.

  2. 02

    Review

    Cloud opens a setup pull request with a pinned Action and least-authority baseline. It never merges it.

  3. 03

    Run

    GitHub Actions executes Jern with your runner and provider secret under the protected policy.

  4. 04

    Inspect

    The team receives repository-bound provenance, lifecycle state, usage, and encrypted run evidence.

The boundary is the product
