Pilot privacy notice

Privacy without mystery.

This notice describes the current Jern Cloud pilot. It is intentionally specific to the product that exists today and will be revised before materially broader processing begins.

Information processed

Jern Cloud processes GitHub profile identity, App installations, selected repositories, organization membership and invitations, Actions run provenance, token reservations, lifecycle metadata, and uploaded Jern traces. Traces can contain task text, model responses, tool inputs and outputs, policy decisions, and file content observed during a run.

Why it is processed

The service uses this information to authenticate users and runners, scope repository access, authorize governed runs, enforce workspace admission budgets, retain encrypted evidence, provide the dashboard, diagnose failures, protect the service, and operate a paid pilot.

Marketing measurement

Jern does not use a third-party analytics script on this site. When a visitor chooses “Start with GitHub,” the control plane records one bounded page-position label such as homepage or pricing in its service log. The event does not include a browser identifier, the visitor's GitHub identity, or arbitrary query text.

Credentials and secrets

Jern Cloud does not request or store customer model-provider keys. GitHub OAuth user tokens and App installation tokens are transient and are not persisted. Random browser and run credentials are stored only as SHA-256 digests.

Retention

The Founding Team pilot includes a target 30-day evidence-retention period. Until automated retention enforcement and customer-visible deletion controls are complete, pilot retention and deletion are handled with each design partner as an onboarding condition. Account, authorization, security, and billing records may be retained longer where needed to operate and defend the service.

Sharing

Data is processed by infrastructure vendors required to operate Jern Cloud, currently including GitHub, Fly.io, and the managed infrastructure backing the deployed service. Jern Cloud does not sell personal information or use retained traces to train models.

Your choices

GitHub repository access can be changed from the App installation settings. Signing out ends the browser session. Pilot teams can request evidence or account deletion through their onboarding contact. Security reports should use private vulnerability reporting.

Changes

Material changes will be dated here and communicated to active paid pilot teams before they take effect.

Effective: August 26, 2026.
